# 整えるダイエットサポート | ととのサロン

ととのサロンの受講生向け、やさしい体重・食事・体調記録ツール。スマホのブラウザで開くだけで使えます。

**公開URL**: https://tomominblog.github.io/totono-diet-support/

## 機能

- ○ **今日の記録** — 体重、朝・昼・夜・間食、睡眠、疲れ、気分、おなか、自由メモを日ごとに保存
- 💬 **入力ごとの返事** — 記録するたびに、内容に合わせた短くやさしいメッセージを表示
- 🍽️ **わたしの目安** — 生年月日・性別・身長・体重・活動量から、1日の目安カロリーを計算
- 📈 **ふり返り** — 体重グラフと、食事・体調の記録を日ごとに表示
- 💡 **食事のヒント** — 食べ方のコツ、食材からのメニュー提案、食事アイデア集
- ⚖️ **詳しいツール** — BMI・年齢別の体重範囲、カロリー・PFCの詳細計算
- 💾 **バックアップ** — 端末内の記録をJSONで保存・復元

## 技術メモ

- 単一 `index.html`（バニラHTML/CSS/JS、ビルド不要）
- データはすべて端末の localStorage に保存（サーバー送信なし）
  - `totono-diet-weight-v1` — 体重記録
  - `totono-diet-memo-v1` — 食事メモ
  - `totono-diet-profile-v1` — プロフィール・目標体重
  - `totono-diet-daily-v2` — 日ごとの体重・食事・体調・メモ
- 年齢別目標BMI範囲・年代別基礎代謝の参考値は厚生労働省「日本人の食事摂取基準（2025年版）」、BMI分類は日本肥満学会に準拠
- manifest.json + アイコンで「ホーム画面に追加」に対応
